# Multidimensional Ecom AI

Plataforma Inteligente de Análise Multidimensional de E-Commerce: Consolidação de Avaliações Multi-Fonte e Diagnóstico de Satisfação.

## Site do projeto

A página institucional está em `index.html` e utiliza os arquivos estáticos de `assets/`. No GitHub Pages, mantenha a publicação pela branch `main` e pela pasta `/(root)`.

## Estrutura

- `index.html`: apresentação do projeto (GitHub Pages).
- `assets/css/styles.css`: identidade visual e layout responsivo.
- `assets/js/main.js`: interações da navegação mobile.
- `amazon.js` e `mercadolivre.js`: scripts de coleta de avaliações nas respectivas plataformas.
- `multidimensional-ecom-ai/src/`: módulos Python de carregamento de dados, classificação de satisfação e recomendação.
- `main.py`: execução de exemplo dos módulos.

> A página é uma apresentação estática. Os indicadores e gráficos ilustrativos não representam resultados reais nem executam os modelos Python ou a coleta de avaliações em tempo real.
